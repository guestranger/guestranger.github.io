适用范围与版本状态

本草稿适用于 Battery Lab Android 应用及本开发者网站，依据已检查的开发版本 0.1.34-recording-recovery（构建 37）编写。发布前须确认负责开发者的身份与联系方式、生效日期、发行地区及最终版本的实际行为。

已检查版本在本地处理电池测量数据，未集成 Google AdMob SDK。下方广告章节仅说明未来可能的集成，不代表当前已收集广告数据。每次发布时应针对实际分发的安装包重新核对本政策和 Google Play 数据安全表单。

本地保存的测量数据

当你明确启动记录后，应用会保存 Android 可提供的电池信号，例如电量、电流、电压、温度、充电或连接状态、时间戳、序列号，以及数据有效性和新鲜度信息。记录与导出文件还可能包含设备、Android 系统和应用版本等元数据。

这些记录用于设备上的图表、充放电统计、模型拟合及续航估算。应用私有存储还包含模型、拟合输入归档、历史摘要和有容量上限的录制诊断日志。诊断信息可能包含服务事件、错误详情、进程退出证据及存储和内存信息；诊断报告不包含完整的原始采样负载。

已检查的应用不会自动将这些电池记录上传至开发者服务器。本地存储并不意味着导出文件或未来广告 SDK 具有相同的数据处理方式。

由你主动保存或分享的导出文件

导出由你通过 Android 文件选择器主动发起。根据导出类型，文件可能包含原始电池记录、详细时间戳、设备标识或元数据、拟合模型、配对原始输入归档或诊断信息。保存文件本身不会将其发送给开发者。

保存位置由你选择。支持云存储的文件提供商可能依据其自身条款，将文件上传至你的账户。若之后通过邮件、上传或其他方式分享，收件人或相关服务将获得文件。分享前请检查并移除不必要的信息。删除应用中的副本不会删除已分享的其他副本。

未来可能使用 Google AdMob 广告

已检查版本尚未集成广告。未来版本可能使用 Google AdMob。若启用，Google 及已配置的广告合作伙伴可能处理 IP 地址、广告标识符或其他设备标识、广告互动及诊断信息，用于广告展示、效果衡量和防欺诈。IP 地址可能用于推断大致位置。实际收集情况取决于 SDK、配置、用户同意及适用要求。

这与本地电池测量数据不同；本草稿不授权向广告商发送原始电池记录。非个性化广告也不一定意味着完全不收集数据。启用广告前，开发者须确认 SDK 和所有聚合广告合作伙伴，更新政策及商店声明，并实现所需的同意和隐私控制。本草稿不声称当前版本已提供这些控制。

请参阅 Google Mobile Ads SDK 数据披露、Google 隐私政策及 Google 广告说明。引入广告后，正式政策须说明实际的隐私选项入口、适用选择、数据接收方、跨境传输及保留方式。开发者无法承诺删除由 Google 独立持有的数据。

数据保留与删除

  • 原始测量数据：保存在本地，除非你主动删除或启用可选的自动原始数据清理。清理与自动拟合为独立设置，在已检查版本中默认关闭，并以归档完整、摘要持久保存等条件为前提，不保证所有数据在 48 小时后无条件删除。
  • 历史：应用展示滚动的七个自然日历史；这不表示所有底层记录都会在七天后过期删除。
  • 模型及拟合输入归档：可能持续保存在设备中，没有自动过期机制。删除实时原始数据不会删除独立历史数据或配对归档；当前尚无专门的归档删除界面。
  • 诊断：近期事件保存在两个各为 256 KiB 的有界日志文件中，旧事件轮换移除；导出的报告单独保留。
  • 清除全部应用私有数据：可在 Android 设置 → 应用 → Battery Lab → 存储 → 清除存储空间，或卸载应用。不同设备的名称可能不同。操作前请导出所需文件；这些操作会移除本地应用记录和设置。
  • 导出文件：保留在你选择的位置，直到你在那里删除，包括云端副本及提供商的备份。清除应用存储不会删除这些文件。
  • 支持通信：若你联系开发者，邮件服务商和开发者可能保留消息及附件。在启用公开联系渠道前，开发者须确认邮件服务商及支持信息保留期限。

对于未来的广告数据，请查看 Google 的相关政策与隐私控制，不能假定删除本地应用即可删除广告数据。

数据分享与用户选择

已检查版本不会自动将电池记录分享至开发者服务器，也未集成广告 SDK。你选择的保存位置及收件人可能按前述方式获得导出文件。在已检查的实现中，未发现电池记录出售机制。

你可以控制录制、导出，以及相互独立的自动拟合和清理设置，也可以只停止记录而不导出。对于主动发送给开发者的信息，如需提出隐私问题或适用的访问、删除请求，请在下方联系渠道确认后使用。开发者无法获取仅存在于你设备上的记录。

数据安全

测量数据保存在 Android 应用私有存储中，受设备操作系统保护。已检查版本禁用了 Android 自动应用备份。请勿假定应用会对每个数据库或导出文件另行加密；本政策不作此保证。设备被入侵、未锁定访问及保存在私有存储之外的文件均可能导致数据泄露。请保护设备安全，谨慎分享原始文件和诊断报告。

网站托管与外部链接

本静态网站不包含广告 SDK、分析脚本、跟踪像素、联系表单或应用数据库，不自行设置 Cookie，也不使用浏览器存储。语言切换使用普通链接。

若网站托管于 GitHub Pages，GitHub 会出于安全目的记录访客 IP 地址。托管日志与 Android 应用的电池记录相互独立。外部链接遵循目标网站的数据处理方式。请参阅 GitHub Pages 数据收集说明及 GitHub 隐私声明。

适用人群与政策更新

本草稿并未确立面向儿童的服务。正式发布前须审核目标用户、Google Play 目标年龄声明，以及未成年用户的广告处理方式；此处不声称已实现年龄验证或监护人同意流程。

当版本行为改变时，包括加入广告或新的数据接收方之前，须更新本政策，注明生效日期，并按适用要求提供通知或征得同意。网站提供英文和简体中文版本，两者均须一致审核。
