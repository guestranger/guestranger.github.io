使用 Battery Lab

Battery Lab 是一款正在测试中的电池监测与分析工具。请仅在你有权操作的设备上使用，并负责任地处理导出文件及他人信息。录制需要明确启动；不同 Android 设备可提供的信号和后台行为有所不同。

测量与估算

Android 可能提供缓存、稀疏或不可用的读数。休眠期间采样可能暂停。拟合、电量容量、阻抗与续航结果取决于输入数据及模型假设，不属于经过校准的电池健康证明、实验室测量、安全诊断或对剩余使用时间的保证。

请勿依赖本应用判断损坏或过热的电池是否安全，应遵循设备制造商的指导。

你的记录与导出文件

录制启停及文件导出由你控制。清除存储、卸载应用或启用清理前，请保存所需副本。清除应用数据可能永久移除本地记录。导出至其他位置的文件仍由你及相应服务提供商的条款管理。

Battery Lab 隐私政策分别说明本地测量、导出及未来可能的广告。

可用性与变更

测试版本可能包含错误、调整功能，或在更新后产生不同结果。本条款不承诺连续录制、永久保存数据、支持响应时间或服务不间断可用。更新正在录制的设备前，请先查看版本说明。

本草稿网站尚未提供公开下载链接。未来可能的广告集成并非当前功能，也不会仅凭此处提及而改变本条款。

本条款不转移开发者软件或网站材料的所有权，也不赋予开发者对你的导出记录的所有权。第三方软件仍适用其各自许可证。Android、Google Play、Google AdMob 和 GitHub 均为第三方服务或标识；提及它们不表示获得背书。
